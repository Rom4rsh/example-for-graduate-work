# Дипломный проект: Система управления объявлениями

**Команда:** Калинин Олег, Аршинов Роман

**Технологии:** 
Java 11,
Spring Boot 2.7.15,
Spring Web (REST API),
Spring Data JPA / Hibernate,
Spring Security,
JWT (nimbus-jose-jwt),
PostgreSQL,
Liquibase,
Lombok,
Swagger / Springdoc OpenAPI,
Maven

**Описание проекта:**  
Данный проект представляет собой веб-приложение для управления объявлениями, пользователями и комментариями. Пользователи могут регистрироваться, аутентифицироваться, создавать объявления, оставлять комментарии, а также редактировать свои данные и аватар.

---

## Функциональные возможности

### 1. Аутентификация и регистрация
- Вход по логину (email) и паролю.
- Регистрация нового пользователя с указанием имени, фамилии, телефона и роли.
- Обновление пароля авторизованного пользователя.

### 2. Пользователи
- Просмотр информации об авторизованном пользователе.
- Редактирование информации пользователя (имя, фамилия, телефон).
- Обновление аватара пользователя.

### 3. Объявления (Ads)
- Получение списка всех объявлений.
- Создание нового объявления с изображением.
- Получение расширенной информации об объявлении.
- Обновление информации об объявлении.
- Удаление объявления.
- Получение объявлений текущего авторизованного пользователя.
- Обновление изображения объявления.

### 4. Комментарии
- Просмотр всех комментариев конкретного объявления.
- Добавление нового комментария.
- Редактирование существующего комментария.
- Удаление комментария.
